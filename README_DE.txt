JARVIS iPad 0.1

Diese Version ist eine sichere kleine Web-App für iPad/iPhone.
Sie braucht keinen Jailbreak und keine unbekannte App-Installation.

Funktionen:
- Mikrofon-Taste
- deutsche Spracherkennung (Browser Web Speech API)
- deutsche Sprachausgabe
- Uhrzeit und Datum
- Wetter über Open-Meteo
- keine PC-Steuerung und keine Systemänderungen

Für Mikrofonzugriff sollte die Seite über HTTPS geöffnet werden.
In Safari muss der Mikrofonzugriff erlaubt werden.

Für eine echte iPad-Nutzung:
1. Projekt auf einen Webserver hochladen (HTTPS).
2. Die Seite in Safari öffnen.
3. Mikrofonzugriff erlauben.
4. Safari: Teilen -> Zum Home-Bildschirm.

Hinweis: Safari/iPadOS unterstützt Web Speech nicht in jeder Version
gleich. Wenn Safari keine Spracherkennung anbietet, braucht die nächste
Version eine andere Sprachschnittstelle.
